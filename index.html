Chrome eklentisini geliştirici modu ile bir kez ekle; sonra tarayıcıdan dosya seçebilirsin.

MYC Sending App · Yerel ağda kontrollü dosya paylaşımı

Chrome Companion

  1. MYC Sending App masaüstü uygulamasını aç.
  2. Uygulamadaki Chrome anahtarını kopyala düğmesine bas.
  3. Chrome’da chrome://extensions yaz.
  4. Sağ üstten Developer mode seçeneğini aç.
  5. Load unpacked düğmesine basıp paketteki extension klasörünü seç.
  6. Eklentiyi aç, anahtarı yapıştır ve dosyanı seç.

Dosya, uygulamada ikinci kez onay bekler. Bu sayede tarayıcı tek başına dosya gönderemez.
